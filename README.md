# Vedhugger-s-Realm
Vedhugger's Realm — это кастомная Minecraft-сборка (модпак) на Forge 1.20.1 про строительство, декор и спокойное исследование мира.  Не техно и не хардкор: упор на дома, мебель, красивые биомы и уютное выживание. Своё меню и атмосфера. Create в сборке нет — тут важнее руками строить и жить в мире, а не крутить заводы.
